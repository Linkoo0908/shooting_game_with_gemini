# Advanced Shooting Game

Pygame을 사용하여 개발된 간단한 아케이드 스타일의 슈팅 게임입니다. 본 프로젝트는 Gemini CLI를 활용한 바이브 코딩(Vibe Coding) 방식으로 개발되었습니다. 플레이어는 우주선을 조종하여 몰려오는 적들을 물리치고, 경험치를 획득하여 다양한 능력을 업그레이드하며 최고 점수에 도전합니다.

## ✨ 주요 기능

*   **우주선 조종:** 좌우 방향키를 사용하여 플레이어 우주선을 조종합니다.
*   **총알 발사:** 스페이스바를 눌러 총알을 발사합니다. 미사일 레벨에 따라 발사되는 총알의 수가 증가합니다.
*   **적:** 화면 상단에서 다양한 체력을 가진 적들이 등장합니다. 적을 처치하면 점수와 경험치를 획득합니다.
*   **레벨업 시스템:**
    *   적 처치 시 경험치(XP)를 획득합니다.
    *   일정 경험치 도달 시 레벨업하며, 5가지 능력치 중 3가지 무작위 선택지를 통해 업그레이드할 수 있습니다.
    *   **업그레이드 종류 (각 6단계):**
        *   **이동 속도:** 플레이어 우주선의 이동 속도 증가.
        *   **공격력:** 총알의 데미지 증가 (총알 색상 변화로 시각적 피드백 제공).
        *   **발사 딜레이:** 총알 연사 속도 증가.
        *   **데미지 방어:** 적과 충돌 시 일정 시간 무적 상태 (반투명 보호막으로 시각적 피드백 제공).
        *   **보조 미사일:** 자동으로 적을 공격하는 보조 미사일 발사 (플레이어 옆에 보조 기체 표시).
*   **아이템:** 일정 시간마다 미사일 레벨업 아이템이 등장합니다. 미사일 레벨 5 달성 후에는 연속 획득 시 경험치 보너스를 제공합니다.
*   **난이도 조절:** 시간이 지남에 따라 적의 체력이 증가하고, 동시에 생성되는 적의 수가 늘어나 게임의 난이도가 점진적으로 상승합니다.
*   **우주 배경:** 별들이 반짝이며 스크롤되는 동적인 우주 배경.
*   **게임 오버 및 재시작:** 플레이어 우주선이 적과 충돌하여 게임 오버 시, 최종 점수와 처치한 적의 수를 표시하고 재시작 버튼을 제공합니다.

## 🚀 실행 방법

1.  **Python 설치:** Python 3.x 버전이 설치되어 있어야 합니다.
2.  **의존성 설치:** 프로젝트 루트에서 다음 명령어를 실행하여 필요한 라이브러리를 설치합니다.
    ```bash
    pip install -r requirements.txt
    ```
3.  **게임 실행:** 프로젝트 폴더로 이동하여 `main.py` 파일을 실행합니다.
    ```bash
    python main.py
    ```

## 🎮 조작법

*   **좌우 이동:** ← (왼쪽 방향키), → (오른쪽 방향키)
*   **총알 발사:** Spacebar (스페이스바)
*   **레벨업 업그레이드 선택:** 마우스 클릭

## 🛠️ 기술 스택
